# NovaCut — Free CapCut Alternative

**Privacy-first • No watermarks • Local-only • Open source**

![Status](https://img.shields.io/badge/Status-v0.7%20Beta-00f5c4) ![License](https://img.shields.io/badge/License-MIT-green)

## CapCut-style features (v0.7)

- Stickers (emoji overlays)
- Voiceover recording from mic
- Flip horizontal / vertical
- Fade in / fade out per clip
- Speed presets (0.5x – 2x)
- More text styles (Outline, Neon)
- CapCut-inspired dark UI
- Multi-track, trim, ripple, markers, export, and more

## Quick Start

Open `index.html` in **Chrome**.

```bash
npx serve .
```

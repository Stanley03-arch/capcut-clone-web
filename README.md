# NovaCut — Free CapCut Alternative

**Privacy-first • No watermarks • Local-only • Open source**

![Status](https://img.shields.io/badge/Status-v0.6%20Beta-00f5c4) ![License](https://img.shields.io/badge/License-MIT-green)

## CapCut-inspired UI (v0.6)

Full dark CapCut-style interface:
- Pure black background + teal accent (#00f5c4)
- CapCut-like top bar, media panel, inspector, timeline
- Rounded clips, thin playhead, compact transport
- Track mute/solo, waveforms, markers

## Features

- Multi-track timeline (Video / Audio / Text)
- Edge trim, duplicate, ripple delete, snap
- Playhead scrub, markers, clip nudge
- Color + opacity controls
- Transitions, effects, text overlays
- Auto-save, load/save project
- Fullscreen preview
- Multi-clip export to WebM

## Quick Start

Open `index.html` in **Chrome**.

```bash
npx serve .
```
